# Binaries the MCP bash proxy (bash_mcp_server.py) is permitted to run
# inside /workspace. One name per line; blank lines and '#' comments
# are ignored.
#
# This file lives under the /workspace bind mount, not the image's
# COPY'd /app layer -- edit it on the host and FileAllowlist (see
# lib/common.py) picks up the change on the next request, by mtime,
# with no container rebuild or restart needed.

ls
cat
grep
find
wc
head
tail
python3
pip
pytest

# git: needed so a push/pull can go through this proxy instead of
# requiring shell access on the WSL2 host directly. No narrower than
# python3/pip above -- those already permit arbitrary code execution,
# so gating git to specific subcommands wouldn't raise the actual
# security ceiling, just add friction.
git

# gh: GitHub CLI, added 2026-08-06 alongside the ssh deploy-key mount
# and image-level gh install (see Dockerfile) -- Arunas's auth split:
# git push/pull goes over ssh, everything else (PRs, issues, releases)
# goes through gh's own token (GH_TOKEN, see docker-compose.yml). Same
# reasoning as git above: no narrower than what's already allowlisted.
gh

# chmod: needed because file-edit tools that write into /workspace
# from outside the container (Filesystem MCP, remote edits) don't
# preserve or set the execute bit -- see start.sh and build.sh, both
# of which needed a manual chmod +x after being edited that way. This
# is the live test of the allowlist config actually refreshing: add
# the line, no container restart, next run_command('chmod', ...) call
# just works.
chmod

# gcc: added 2026-08-10 alongside GPU passthrough. core/'s build runs
# through `make`, so gcc would work as a child process without being
# listed here -- this entry is for calling the compiler directly when
# testing a single kernel against the device, which is the common case
# for GPU work. Same reasoning as git/python3 above: no narrower than
# what is already permitted.
gcc

# rocminfo: device verification. Read-only, reports the agents ROCm
# can see, and is the fastest way to confirm /dev/dxg passthrough is
# actually working from inside this container rather than assuming it
# from the compose file. Expect Agent 2 = gfx1100 (RX 7900 XT).
rocminfo

# hipcc: ROCm's compiler driver, mounted in from the host's /opt/rocm
# rather than installed in the image. Needed to build anything that
# actually targets the GPU; gcc above only covers the CPU substrate.
hipcc

# make: added 2026-08-08 so the new root Makefile (lint/build/deploy/
# verify/e2e/all, wrapping tools/pipeline.sh with standard DevOps
# target names -- see Makefile itself) is callable through this proxy
# via run_command(binary="make", args=[...]) rather than needing
# `bash` allowlisted (still an open, deliberately unresolved decision
# -- see tools/pipeline.sh's own comments). NOTE: allowlisting alone
# isn't enough -- `make` also needs to actually be installed in the
# image (Dockerfile), which needs a rebuild to take effect; this line
# refreshes live via mtime same as the rest of this file, but the
# binary itself won't be usable until that rebuild happens.
make
