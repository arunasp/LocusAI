# LocusAI

From-scratch biologically-inspired synthetic mind project -- explicitly
not another LLM/pattern-matcher, aims to translate biological->synthetic
mind processes rather than weights-matching-and-prediction.

## Repo layout

- `tools/` -- local dev tooling (git/bash MCP servers for Claude Desktop
  integration). See [tools/README.md](tools/README.md) for setup.
- Everything else: TBD as the actual model/training code lands.
